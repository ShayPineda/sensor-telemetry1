## Sensor Telemetry Logger

A Python script that simulates temperature sensor readings, logs them to the terminal, and saves them to a CSV file with timestamps.

## How to run
python sensor_logger.py

## Output
Generates sensor_log.csv with timestamp and temperature columns.
